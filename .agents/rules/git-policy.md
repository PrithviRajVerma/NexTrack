# Git Commit & Push Policy

**MANDATORY SYSTEM INSTRUCTION FOR ANTIGRAVITY (AGY):**
- **Do NOT commit (`git commit`) or push (`git push`) changes unless the user explicitly asks you to do so.**
- Creating, editing, and testing code, inspecting repository state (`git status`, `git diff`, `git log`), and staging files (`git add`) are permitted as needed.
- Autonomous, proactive, or unsolicited `git commit` and `git push` actions are strictly prohibited.
- Always wait for the user to explicitly say "commit", "push", or give direct instruction before performing any commit or push operation.
