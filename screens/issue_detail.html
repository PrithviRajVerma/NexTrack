NEXT-42: Optimistic UI update rollback on 409 Conflict with backend workflow validator

Mark as Done Start Review Revert to To Do

Description

When a state transition request results in a 409 Conflict error due to concurrent state updates on the backend workflow validator, the client currently keeps the optimistic local cache state. We need to implement a clean transaction rollback mechanism to restore the previous state version and trigger an actionable notification toast.
