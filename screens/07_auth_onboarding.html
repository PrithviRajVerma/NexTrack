Module 8.1 & Section 7.4

Cryptographic Boundary Security & Token Rotation

NexTrack enforces zero-trust authentication using asymmetric RS256 JWT access tokens paired with HttpOnly stateful refresh tokens with automated family theft detection.

✓
RS256 Asymmetric Keypair
Tokens verified in-memory using 2048-bit RSA public key without database bottlenecks.
✓
Refresh Token Family Theft Detection
Replay attack with revoked refresh token automatically invalidates all sessions in the family.
✓
Anti-Enumeration Login Protection
Constant-time BCrypt strength-12 verification with generic error responses prevents user probing.
Access Token TTL: 15 Minutes (900s)
Refresh Cookie: HttpOnly; SameSite=Strict
Rate Limiter: Bucket4j (5 req/min per IP)
