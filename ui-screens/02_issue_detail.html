NT-101 Sprint Priority

GitHub Webhook Inbox 2-phase worker with lease ownership token verification

Workflow State Machine (Centralized Transition Engine) Valid Transitions Only

Description

Implement the 2-phase polling worker that claims pending raw webhook events from the webhook_inbox_events table and transitions them through idempotent payload processing without blocking the initial webhook response.

// Phase 1: Atomic lease claim
SELECT id FROM webhook_inbox_events WHERE status = 'PENDING' FOR UPDATE SKIP LOCKED LIMIT 50;
// Phase 2: Normalized domain event dispatch
UPDATE webhook_inbox_events SET status = 'PROCESSED' WHERE id = :id AND lease_token = :token;

Acceptance Criteria:

  • HMAC signature validated against raw request bytes before persistence.
  • Deduplication enforced via UNIQUE(provider, delivery_id).
  • Lease heartbeat mechanism releases deadlocks if worker crashes mid-transaction.
  • Testcontainers integration test verifies 100 concurrent incoming webhooks without duplicate writes.
